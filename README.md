# Yesahosin

Persistent notes for a farm project. These files preserve confirmed context
between devices and conversations; they do not recover missing chats or
guarantee that every Copilot interface loads them automatically.

To resume, tell Copilot: "Read the project notes in Sy1ux/Yesahosin before
continuing." To save progress, ask it to update and commit these notes.

- `PROJECT.md`: confirmed project facts and missing information.
- `DECISIONS.md`: agreed decisions and their reasons.
- `CHAT_LOG.md`: concise discussion summaries, not full transcripts.
- `TODO.md`: outstanding work.
- `.github/copilot-instructions.md`: guidance for Copilot when this repository
  is available as context.

This repository is public. Do not add private conversations, credentials,
personal information, or confidential farm details.
